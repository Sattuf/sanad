# ADR-0008: رفض فوري عند عدم تطابق نوع المستند مع نوع الممارسة
التاريخ: 2026-09-23
الحالة: مقبول

## السياق
المرجع متعارض ظاهرياً: §3.2 يقترح تحققاً في Handler طلب الترقية، بينما §6.1 و§8.1(15) و§10.11(3) تفترض أن الطلب غير المتطابق يصل للمراجعة ثم يُرفض إدارياً بـ `DocumentTypeMismatch`.

## القرار
- عند الإرسال: يُقبل أي نوع مستند من **القائمة المسموحة العامة** (مستندات طبية أو شرعية)، لا غيرها.
- عند المراجعة: قائمة المنسق تُظهر `documentMatchesDeclaredType` صراحة. إن اختار المنسق الاعتماد (كاملاً أو مشروطاً) والمستند لا يطابق النوع المُعلَن، **يُسجَّل رفض فوري بسبب `DocumentTypeMismatch`** وتعيد الاستجابة `autoRejectedForDocumentMismatch = true`. لا يوجد "اعتماد شرطي على أمل التصحيح".
- Domain نفسه يرفض `Approve()` على مستند غير مطابق (حزام أمان ثانٍ).

## الأثر
- الطبيب المرخّص والشيخ/الراقي مساران متكافئان؛ الفرق الوحيد هو قائمة المستندات المقبولة لكل منهما (`VerificationDocumentTypes`).
