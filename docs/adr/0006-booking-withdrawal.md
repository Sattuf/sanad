# ADR-0006: سحب طلب الحجز قبل القبول
التاريخ: 2026-09-23
الحالة: مقبول

## السياق
جدول الانتقالات في `02-domain-model.md` §2.5 لا يسمح للمستفيد بإلغاء طلب ما زال `Submitted` أو `UnderReview`، فيبقى الموعد محجوزاً مبدئياً بلا مخرج.

## القرار
- إضافة `Submitted → Cancelled` و`UnderReview → Cancelled` (بقية الجدول دون تغيير).
- الحجز يُنشأ مباشرة في `UnderReview` (Draft → Submitted → UnderReview) لأنه لا توجد خطوة مراجعة منفصلة بين الإرسال ومراجعة المختص.

## الأثر
- الإلغاء يحرر الفترة (`SlotStatus.Open`) فوراً.
