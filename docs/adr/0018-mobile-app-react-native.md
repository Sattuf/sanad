# ADR-0018: تطبيق الجوال الأصلي بـ React Native (Expo) لجمهور 100 ألف مستخدم
التاريخ: 2026-10-01
الحالة: مقبول — يعدّل `references/10-frontend-architecture.md` §10.1 ويكمّل ADR-0017

## السياق
- الهدف: تطبيق متجر حقيقي بتجربة أصلية، لجمهور مستهدف 100 ألف مستخدم مسجَّل.
- سند يملك واجهة ويب React + TypeScript (~8,100 سطر) فيها منطق لا يجوز أن ينحرف: التقاط إشارة الطوارئ،
  نصوص القرآن المطابقة حرفياً (ADR-0016)، الأدعية والأوراد، أنواع DTOs، وقواعد الجلسة (ADR-0014).
- خُيّر بين React Native وFlutter (واستُبعد تغليف الويب بـ Capacitor لأن المطلوب تجربة أصلية كاملة).

## المقارنة

| المعيار (الوزن) | React Native + Expo | Flutter |
|---|---|---|
| إعادة استخدام الكود الحالي (25%) | 9 — الأنواع، العميل، Zod، المحتوى، i18n، منطق السلامة | 2 — إعادة كتابة كاملة بـ Dart |
| تطابق ضوابط السلامة ونص القرآن (20%) | 10 — حزمة مشتركة واحدة يختبرها الويب والجوال | 5 — نسخة ثانية تحتاج مزامنة يدوية |
| زمن الوصول للمتجر (20%) | 8 — ~12 أسبوعاً | 6 — ~16 أسبوعاً |
| الأداء والتجربة الأصلية (15%) | 8 — المعمارية الجديدة + FlashList + Reanimated | 9 — محرك رسم خاص وثبات بصري |
| فريق واحد بلغة واحدة (10%) | 10 — TypeScript للويب والجوال | 5 — Dart + TypeScript |
| البناء والتحديث (10%) | 9 — EAS Build/Submit/Update | 7 — Codemagic/fastlane، بلا تحديث فوري رسمي |
| **المجموع من 10** | **9.1** | 5.4 |

ملاحظة: **كلا الخيارين يتحمّل 100 ألف مستخدم بلا مشكلة**؛ التحمّل يُحسم في الخادم لا في تقنية التطبيق (راجع الخطة §6).
Flutter كان سيفوز لو بدأنا من الصفر بلا كود TypeScript.

## القرار
- **React Native عبر Expo** (أحدث SDK مستقر، المعمارية الجديدة مفعّلة) مع Expo Router وEAS.
- **مستودع موحّد** بمساحات npm: `packages/shared` (أنواع، عميل API، مخططات Zod، كشف إشارة الطوارئ، المحتوى، i18n)
  يستخدمه `frontend/` (الويب) و`mobile/` (التطبيق). أي تعديل على منطق السلامة يمر باختبارات الطرفين.
- **الإصدار 1.0 للمستفيد**؛ بوابة المختص في 1.1؛ بوابات التنسيق والإدارة تبقى على الويب فقط (2FA وصلاحيات حساسة).
- **تذكير الأذكار على الجوال محلي** (`expo-notifications` مجدولة على الجهاز) — لا حمل على الخادم.
- **إشعارات الخادم** (رسالة جديدة، تحديث حجز، توصية) عبر FCM HTTP v1 لـ Android وiOS، بنص عام فقط — تُفعَّل قناة FCM في ADR-0009.

## الأثر
- الخادم: دخول Google وApple الأصلي بـ ID Token، تسجيل رمز الجهاز للإشعارات، نقطة «الحد الأدنى للإصدار»،
  وتجهيزات التوسّع في `docs/mobile-app-plan.md` §6 (إلزامية قبل الإطلاق).
- التفاصيل والجدول الزمني ومعايير القبول: `docs/mobile-app-plan.md`.
