# ADR-0023: تطبيق الجوال بـ Flutter بدل React Native، بواجهة مطابقة للويب
التاريخ: 2026-10-15
الحالة: مقبول — **يحلّ محلّ ADR-0018**

## السياق
- ADR-0018 اختار React Native (Expo) لأنه يعيد استخدام كود TypeScript ويشارك الويب منطق السلامة ونص المصحف.
- بعدها صار الويب «رفيق السكينة اليومي» (ADR-0022) بهوية «سكينة الفجر»، وطلب صاحب المنتج تطبيقاً بـ **Flutter** بواجهة **مشابهة للويب وقريبة منه**.
- تطبيق RN القائم (`mobile/`، نحو 4,000 سطر) لم يُطلق في المتاجر بعد، ولا يحمل ميزات الرفيق ولا الهوية الجديدة.

## القرار
1. **Flutter (الإصدار المستقر الحالي 3.44 / Dart 3.12)** لتطبيق المستفيد على Android وiOS، في `mobile_flutter/` أثناء البناء،
   ثم يحلّ محل `mobile/` عند الإطلاق ويُحذف تطبيق RN.
2. **الويب مرجع التصميم**: رموز الألوان تُولَّد آلياً من `frontend/src/styles/index.css` إلى Dart، ونفس الخطوط، ونفس المكوّنات واحداً بواحد.
3. **مصدر واحد للمحتوى والسلامة لا يُنسخ يدوياً**: `packages/shared` يبقى المرجع. مولّد يصدّر المصحف والأذكار والبرامج والميزان
   والنصوص وأنماط كشف الخطر إلى JSON يقرؤه التطبيق، وفحص في CI يرفض أي JSON غير مطابق للمصدر.
   ولتحقيق ذلك يُنقل محتوى الرفيق من `frontend/src/content` إلى `packages/shared/src/content`.
4. **اختبارات تطابق مشتركة**: متجهات اختبار (نصوص خطر/أمان، توحيد العربية، بحث الميزان، تقييم الاختبار، تشفير المذكّرة)
   في ملف JSON واحد يشغّله Vitest وflutter_test معاً.
5. **الدخول**: Google على Android وiOS، و**Sign in with Apple على iOS** إلزاماً (إرشاد App Store 4.8 عند تقديم دخول طرف ثالث).
   الخادم يدعمهما أصلاً (ADR-0019). لا بريد ولا هاتف في التطبيق، اتساقاً مع الويب.
6. **المعرّف نفسه** `app.sanad` لـ Android وiOS، فيصل تطبيق Flutter كتحديث لأي مختبِر لديه نسخة RN.

## البدائل
- **إبقاء RN وتوحيد واجهته مع الويب**: أسرع ويشارك الكود مباشرة، لكن صاحب المنتج اختار Flutter صراحةً (2026-10-15).
- **Flutter بجانب RN**: تطبيقان في المتجر وصيانة مزدوجة — مرفوض.

## الأثر
- كلفة إضافية: طبقة Dart للعميل والمحتوى بدل الاستيراد المباشر، تعوّضها المولّدات واختبارات التطابق.
- لا «تحديث فوري» رسمي كـ EAS Update؛ نستخدم Shorebird لإصلاحات Dart العاجلة، وبناءً جديداً لما سواها.
- الخادم بلا تغيير جوهري؛ نقاط الجوال في ADR-0019 وتجهيزات التوسّع في ADR-0020 تبقى كما هي.
