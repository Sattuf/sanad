# ADR-0014: الواجهة الأمامية — عميل API مكتوب يدوياً، وتخزين الجلسة، وتقليم الأدوات
التاريخ: 2026-09-24
الحالة: مقبول — **عُدِّل جزئياً بـ [ADR-0024](0024-sharia-only-scope.md)** (نطاق شرعي فقط)

## السياق
المرجع (§10.2) يقترح عميلاً مولَّداً بـ orval وStorybook. في هذه المرحلة، العقد يتغيّر بسرعة، وفريق صغير.

## القرار
- **عميل API مكتوب يدوياً** (`src/api/client.ts` + `types.ts`) يطابق DTOs الخلفية. يوحّد: ProblemDetails ← `ApiError`، تجديد الرمز مرة واحدة عند 401، و**التقاط إشارة الخطر من أي استجابة** (ترويسة `X-Sanad-Emergency-Referral` أو حقل `emergencyReferral`) لرفع شريط الطوارئ فوراً — مسار كود مستقل لا يعتمد على نجاح الطلب. الانتقال لـ orval ممكن لاحقاً من `/swagger/v1/swagger.json` دون تغيير الشاشات.
- **الجلسة**: رمز الوصول (15 دقيقة) في الذاكرة فقط، ورمز التحديث في `sessionStorage` (يُمحى بإغلاق التبويب)، لا `localStorage`. رفض التجديد بـ 400/401 فقط يُخرج المستخدم؛ حد المعدل (429) أو عطل مؤقت لا.
- **Storybook مؤجَّل** (تقليم نطاق — 12 §12.5): نظام التصميم صغير (`components/ui`)، ويُضاف Storybook عند نمو الفريق.
- **الحراسة على العميل عرض فقط**: `RequireRole` يمنع ظهور شاشات لا تخص المستخدم، والحماية الفعلية على الخادم دائماً.
- **CAPTCHA**: العميل يرسل `X-Captcha-Token` إن وُجد رمز Turnstile على الصفحة (`lib/captcha.ts`)؛ تركيب ودجت Turnstile يتم عند توفر مفتاح الموقع للبيئة.

## الأثر
- البيانات التجريبية (`DevDataSeeder`) تعمل في Development فقط، وتسمح بتشغيل اختبارات Playwright محلياً.
