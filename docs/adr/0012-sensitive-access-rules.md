# ADR-0012: قواعد الوصول للنصوص الحساسة والموافقة عليها
التاريخ: 2026-09-23
الحالة: مقبول

## السياق
المرجع يحدد من يقرأ كل نص حساس، لكن "Coordinator بصلاحية إشراف موثّقة صراحة" و"عند تصعيد مرتبط" تحتاج تعريفاً قابلاً للتنفيذ.

## القرار
| النص | يقرؤه |
|---|---|
| "ملاحظتي للمختص" | صاحب الحجز، المختص المُسنَد، أو Coordinator (بـ 2FA) **فقط عند وجود EscalationCase مفتوح** يخص أحد طرفي الحجز |
| ملاحظة المختص الخاصة | كاتبها، ClinicalSupervisor (بـ 2FA)، أو Coordinator عند تصعيد مفتوح مرتبط — **المستفيد لا يصل إليها أبداً (404)** |
| توصية المختص | المستفيد المرسَلة إليه، والمختص الذي كتبها |
| وصف البلاغ | Coordinator (بـ 2FA) |

- كل قراءة من غير المالك تُسجَّل في التدقيق (بيانات وصفية فقط).
- غير المصرَّح له يتلقى **404 لا 403** حيث لا يجوز كشف وجود المورد.
- كتابة "ملاحظتي للمختص" تتطلب موافقة `SensitiveDataProcessing` (تُسجَّل ضمنياً عند تأشير المستخدم عليها في نموذج الحجز). **كاشف الخطر يعمل قبل أي تحقق من الموافقة**، فرفض الطلب لغياب الموافقة لا يحجب معلومات الطوارئ.
