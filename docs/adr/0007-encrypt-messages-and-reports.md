# ADR-0007: تشفير نص الرسائل ووصف البلاغات أيضاً
التاريخ: 2026-09-23
الحالة: مقبول

## السياق
المرجع يعرّف `Message.Body` نصاً عادياً، ولا يذكر وصفاً للبلاغ. عملياً، المستخدم في محادثة مع مختص أو في بلاغ قد يكتب تفاصيل صحية/دينية حساسة.

## القرار
- `Message.BodyEncrypted` و`Report.DescriptionEncrypted` مشفّران بنفس `IFieldEncryptor`.
- يُفك التشفير فقط لعضو المحادثة، وللمنسق عند فتح تفاصيل البلاغ (مع سجل تدقيق `Safety.ReportDescriptionRead`).
- كاشف مؤشرات الخطر يعمل على النص **قبل** التشفير، والإحالة العاجلة لا تعتمد على نجاح الحفظ.
- SignalR يبث المعرّفات فقط (`messageReceived {conversationId, messageId}`) — لا نص عبر القناة اللحظية، ولا يستقبل الـ Hub أي نص من العميل؛ الإرسال عبر REST ليمر بكل ضوابط الـ Pipeline.
