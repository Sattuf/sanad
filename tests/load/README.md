# اختبار الحِمل (k6)

`sanad.js` يشغّل مجموعتين في وقت واحد:

- **زوّار** بلا حساب: الدليل، وصفحة مختص، والأدعية، والقرّاء.
- **مستفيدون مسجَّلون**: لكلٍّ حسابه، ويفتح حسابه ومواعيده ومحادثاته وإشعاراته وتوصياته ومواعيد مختص.

ويفشل الاختبار إن زادت الأخطاء على 1%، أو تجاوز p95 ‏500 ms، أو تجاوز p99 ‏1.5 s.

## التشغيل

الخادم يعمل في Development (بيانات العرض). وكل الطلبات تخرج من عنوان واحد، فتُرفع حدود المعدّل التي تُحسب لكل عنوان IP.
والأدوات المطلوبة: [k6](https://grafana.com/docs/k6/latest/set-up/install-k6/)، وعلى ويندوز: `winget install GrafanaLabs.k6`.

```bash
# 1) الخادم — من جذر المستودع
ASPNETCORE_ENVIRONMENT=Development RateLimiting__AuthPerMinute=100000 RateLimiting__PublicPerMinute=100000 \
RateLimiting__GlobalPerMinute=100000 dotnet run --project src/Sanad.Api -c Release --urls http://localhost:5080

# 2) الحِمل الافتراضي: 50 زائراً + 50 مستفيداً لثلاث دقائق
k6 run tests/load/sanad.js

# حِمل أثقل، أو خادم آخر
k6 run -e VISITORS=200 -e MEMBERS=200 -e HOLD=1m tests/load/sanad.js
k6 run -e SANAD_API_URL=https://staging.example tests/load/sanad.js
```

لا تشغّله على الإنتاج: هو ينشئ حساباً لكل مستفيد افتراضي.

## النتائج (2026-10-23)

البيئة: حاسوب محمول بأربعة أنوية، وk6 والخادم على الجهاز نفسه، وSQLite. وPostgres في الإنتاج أسرع تحت الكتابة المتزامنة.

| الحِمل | الطلبات/ث | p95 | p99 | أخطاء |
|---|---|---|---|---|
| 100 مستخدم، قبل الإصلاح | 88 | 380 ms | 1.2 s | 0% |
| 100 مستخدم | 98 | 22 ms | — | 0% |
| 400 مستخدم | 236 | 48 ms | 76 ms | 0% |

ما كشفه الاختبار:

- **الكتابة إلى الطرفية كانت متزامنة:** كل سطر سجل كان يحجز خيط الطلب، فارتفع p95 من 72 إلى 380 ms.
  صارت الكتابة غير متزامنة (`Serilog.Sinks.Async`)، والسجلات كاملة كما كانت.
- **كل 404 و403 و400 معالَج كان يُسجَّل `ERROR … responded 500`:** سجل الطلبات كان داخل معالج الاستثناءات،
  ومعه سطر ثانٍ من الإطار نفسه. صار السجل خارج المعالج فيرى الحالة النهائية، وكُتم سطر الإطار المكرر.
- **معرّف الترابط كان يضيع من ردود الخطأ:** `X-Correlation-Id` كان يُمسح منها، و`traceId` في جسم الخطأ كان معرّف Activity
  لا يطابق السجلات. صار المعرّف نفسه في الرأس والجسم وكل سطر سجل.
