# سند — رفيق الرقية الذاتية (PWA)

تطبيق ويب تقدّمي مجاني يساعد المسلم على أن يرقي نفسه بنفسه: يختار خطة رقية يعدّها شيخ معروف، يقرأ وردها كل يوم،
يتابع أيامه، ويختم القرآن. لا راقٍ فيه ولا طبيب ولا حجز ولا تشخيص.

يُبنى وفق المهارة `.claude/skills/sanad-ruqyah-app/` (النطاق، ضوابط المحتوى، ونظام التصميم «المخطوطة المُذهَّبة»).

## التشغيل

```bash
cd ruqyah-app
npm install
npm run dev            # http://localhost:5174
npm test               # منطق الخطة والختمة، الخطط، وطبقة الأمان في الواجهة
npm run check:guardrails
npm run build          # dist/ — يُنشر كملفات ثابتة من أي مسار
```

## ما نُفّذ (المرحلة الأولى)

| الجزء | الحالة |
| --- | --- |
| **أول فتح** | ترحيب ← سؤال المدة فقط ← اختيار الخطة ← وقت التذكير (اختياري) ← ورد اليوم الأول |
| **اليوم** | السرلوح والتاريخ الهجري، الجدول، السبحة، «أكمل من حيث توقفت» دون ذكر الأيام الفائتة، سطر الختمة |
| **الخطط** | خمس خطط (٧/٧/١٤/٢١/٤٠ يوماً)، تصفية بالمدة والمعدّ، صفحة الخطة بالإذن والإصدار وتنبيه العلاج، إيقاف وتبديل |
| **القارئ** | آيات بالرسم العثماني وأذكار مع تخريجها، عدّاد التكرار، تكبير الخط حتى ١٥٠٪، منع إطفاء الشاشة، «قرأته من مصحفي» |
| **الختمة** | فردية: وردة الثلاثين بتلة (لوحة المفاتيح مدعومة)، تاريخ مستهدف ووتيرة يومية، الترقيمة عند الإتمام |
| **ادعم** | صفحة واحدة، الزر معطّل حتى تُعتمد الجهة المستقبِلة، تذكير واحد لطيف بعد أول خطة كاملة فقط |
| **الأمان** | زر «طوارئ» في كل سرلوح، ورابط «متى تحتاج مع الرقية إلى طبيب؟» في حاشية كل شاشة |
| **دون إنترنت** | كل النصوص مضمّنة، وعامل خدمة يحفظ التطبيق بعد أول فتح. التقدّم محلي على الجهاز وحده |

## مصدر النصوص

- الآيات من `packages/shared/src/content/quran.ts`: مصحف بالرسم العثماني (QuranEnc، رخصة CC BY-SA 4.0)، مولَّد آلياً ومختبَر حرفياً.
- الأذكار من `packages/shared/src/content/ruqyah.ts` مع تخريجها. لا يُكتب نص قرآني أو ذكر في هذا التطبيق مباشرة.
- `src/content/plans.ts` يرتّب تلك النصوص في أيام فقط.

## قبل النشر الفعلي

- [ ] **المعدّون:** الخطط الآن بأسماء نائبة («المعدّ الأول/الثاني») وموسومة «خطة تجريبية». لكل خطة: إذن مكتوب من الشيخ، مراجعة شرعية من مراجع ثانٍ، فحص الأمان (content-guardrails.md §3)، ثم تعبئة `consentRef` و`consentDate` و`review`.
- [ ] **نص صفحة الأمان** يراجعه مختص نفسي، وتُربط أرقام الطوارئ بجدول تحرّره الإدارة حسب البلد.
- [ ] **الدعم المالي:** تحقّق من سياسات متجري آبل وجوجل، واعتماد جهة مستقبِلة، قبل تفعيل الزر.

## المرحلة التالية

- **الختمة الجماعية:** نيّة اختيارية، رابط دعوة عبر واتساب، توزيع الأجزاء، مزامنة متأخرة — تحتاج نقاط API وحساباً اختيارياً. نموذج `Khatma` و`Rosette` يدعمان بتلات الأعضاء الآخرين مسبقاً.
- **التذكير اليومي:** الوقت يُحفظ الآن؛ الإشعار نفسه يحتاج Push (أو تطبيق الجوال). نصه: «وردك اليوم جاهز.» ولا إشعار عن الأيام الفائتة.
- **الصوت:** بعد ترخيص التلاوات، مع اسم القارئ ومصدر التسجيل تحت المشغّل وتحميل مسبق للخطة النشطة.
