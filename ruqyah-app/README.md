# سند — رفيق الرقية الذاتية (PWA)

تطبيق ويب تقدّمي مجاني يساعد المسلم على أن يرقي نفسه بنفسه: يختار خطة رقية يعدّها شيخ معروف، يقرأ وردها كل يوم،
يتابع أيامه، ويختم القرآن. لا راقٍ فيه ولا طبيب ولا حجز ولا تشخيص.

يُبنى وفق المهارة `.claude/skills/sanad-ruqyah-app/` (النطاق، ضوابط المحتوى، ونظام التصميم «المخطوطة المُذهَّبة»).

## التشغيل

```bash
cd ruqyah-app
npm install
npm run dev            # http://localhost:5174
npm test               # منطق الخطة والختمة، الخطط، وطبقة الأمان في الواجهة
npm run check:guardrails
npm run build          # dist/ — يُنشر كملفات ثابتة من أي مسار
```

## مع الخادم (اختياري)

```bash
cp .env.example .env.local      # VITE_API_URL يشير إلى Sanad.Api
npm run dev
```

دون `VITE_API_URL` يعمل التطبيق محلياً كاملاً. معه تظهر «حسابي»: مزامنة الخطة، الختمة مع الأسرة، وتذكير الإشعارات.
القرار المعماري كاملاً في `docs/adr/0021-self-ruqyah-companion-app.md`.

## ما نُفّذ

| الجزء | الحالة |
| --- | --- |
| **أول فتح** | ترحيب ← سؤال المدة فقط ← اختيار الخطة ← وقت التذكير (اختياري) ← ورد اليوم الأول |
| **اليوم** | السرلوح والتاريخ الهجري، الجدول، السبحة، «أكمل من حيث توقفت» دون ذكر الأيام الفائتة، سطر الختمة |
| **الخطط** | المنشور من الخادم (معدّ بإذن مسجَّل، مراجعة ثانية، فحص أمان، رقم إصدار) ويُحفظ للعمل دون إنترنت؛ والخطط التجريبية المضمَّنة احتياطاً |
| **القارئ** | آيات بالرسم العثماني وأذكار مع تخريجها، عدّاد التكرار، تكبير الخط حتى ١٥٠٪، منع إطفاء الشاشة، «قرأته من مصحفي» |
| **الختمة** | فردية على الجهاز؛ وجماعية: نيّة لا يراها إلا الأعضاء، دعوة عبر واتساب، اختيار الأجزاء أو توزيعها، إشعار واحد عند التمام |
| **حسابي** | دخول اختياري، مزامنة الخطة (دمج الأيام من كل جهاز)، تذكير يومي هادئ بالإشعارات، بلد أرقام الطوارئ، إيقاف العدّادات |
| **ادعم** | صفحة واحدة لا تفتح أي ميزة؛ الزر رابط خارجي يُعدّ في الخادم، ومعطّل حتى ذلك |
| **الأمان** | زر «طوارئ» في كل سرلوح، ورابط الطبيب في كل حاشية، وأرقام البلد من جدول تعتمده الإدارة بعينين |
| **دون إنترنت** | كل النصوص مضمّنة، وعامل خدمة يحفظ التطبيق ولا يخزّن أي طلب للخادم |

## مصدر النصوص

- الآيات من `packages/shared/src/content/quran.ts`: مصحف بالرسم العثماني (QuranEnc، رخصة CC BY-SA 4.0)، مولَّد آلياً ومختبَر حرفياً.
  خطط الخادم تشير إلى المقطع بمفتاحه فقط، واختبار يتحقق أن قائمة المفاتيح في الخادم تطابق المصحف المضمَّن.
- الأذكار من `packages/shared/src/content/ruqyah.ts` مع تخريجها، أو يكتبها مدير المحتوى مع تخريجها في الخطة وتمر بالمراجعة.

## الإدارة (موقع سند ← الإدارة)

- **خطط تطبيق سند** (مدير محتوى): المعدّون وأذونهم، محرّر الخطة بأنماط أيام تتناوب، المراجعة مع فحص الأمان، الإصدارات والسحب.
- **أرقام الطوارئ** (منسق أو مشرف سريري): رقم بمصدره الرسمي، يعتمده موظف آخر، ويُراجع كل ستة أشهر.
- **مؤشرات سند**: عدّادات مجهولة يومية.

## قبل النشر الفعلي

- [ ] إذن مكتوب حقيقي لكل معدّ يُسجَّل مرجعه، ثم المراجعة الشرعية وفحص الأمان لكل خطة.
- [ ] نص صفحة الأمان يراجعه مختص نفسي، وأرقام طوارئ معتمدة لبلدان التشغيل.
- [ ] الدعم المالي: سياسات متجري آبل وجوجل واعتماد الجهة المستقبِلة قبل ضبط `Companion:SupportUrl`.
- [ ] مفاتيح VAPID (ADR-0017) لتفعيل التذكير بالإشعارات، وإضافة أصل التطبيق إلى `Frontend:AllowedOrigins`.
