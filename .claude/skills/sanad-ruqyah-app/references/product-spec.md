## 1. المستخدم والوعد

المستخدم: مسلم عربي يشعر بضيق أو يخشى عيناً أو حسداً أو يريد التحصين، أو أحد أفراد أسرته يبحث له. كثير منهم كبار سن أو يستخدمون هواتف متواضعة.

الوعد: «ورد واضح كل يوم، من شيخ تثق به، تقرؤه بنفسك — مجاناً.»

## 2. الشاشات والتدفقات

### أول فتح (أقل من دقيقة)
1. شاشة ترحيب واحدة: «سند يساعدك أن ترقي نفسك بنفسك، بورد يومي من خطة يعدّها شيخ معروف.»
2. سؤال واحد: «كم يوماً تريد أن تبدأ؟» (٧ / ١٤ / ٢١ / ٤٠). لا أسئلة عن الحالة.
3. عرض 2–3 خطط بهذه المدة، والمستخدم يختار.
4. سؤال اختياري عن وقت التذكير (بعد الفجر / بعد المغرب / قبل النوم).
5. يفتح ورد اليوم الأول مباشرة.

التسجيل اختياري؛ التقدم يُحفظ محلياً، والحساب يُطلب فقط للمزامنة أو للختمة الجماعية.

### اليوم
- السرلوح: «ورد اليوم» + التاريخ الهجري.
- الجدول: اسم الخطة، «اليوم ٤ من ٧»، السبحة، زر «افتح ورد اليوم».
- سطر الختمة: «ختمتك: ١٢ جزءاً من ٣٠» ← الختمة.
- الحاشية: ملاحظة المعدّ أو تذكير بأن الشفاء بيد الله.
- إن انقطع المستخدم: «أكمل من حيث توقفت: اليوم ٤» دون ذكر الأيام الفائتة.

### الخطط
- تصفية بالمدة وبالمعدّ فقط.
- صفحة الخطة: من أعدّها ونبذة عنه، تاريخ الإذن، ما تحتويه يومياً، المدة التقريبية للورد بالدقائق، زر «ابدأ الخطة».
- خطة واحدة نشطة في الوقت نفسه (تبسيطاً)، مع إمكانية الإيقاف والتبديل.

### القارئ
- كل عنصر في الورد كتلة: عنوان (السورة أو الذكر)، النص، العدّاد في الحاشية، زر الاستماع.
- الصوت اختياري ويُحمّل مسبقاً للعمل دون إنترنت؛ النص هو الأساس لأن المستخدم يقرأ بنفسه.
- تكبير الخط، ووضع ليلي، ومنع إطفاء الشاشة أثناء القراءة.
- زر «أتممت ورد اليوم» يتفعّل بعد اكتمال العدّادات، ويمكن تجاوزه بـ«سجّل الورد مكتملاً» لمن قرأ من مصحفه.

### الختمة
- **فردية:** وردة الثلاثين جزءاً؛ النقر على البتلة يسجّل الجزء. اختياري: تاريخ مستهدف يُحسب منه «جزء ونصف يومياً تقريباً».
- **جماعية:** ينشئها المستخدم ويكتب نيّة اختيارية («على نية شفاء والدتي»)، ثم يرسل رابط دعوة عبر واتساب. كل منضم يختار أجزاءه أو تُوزّع تلقائياً. الوردة تُظهر أجزاء الجميع.
- **الإتمام:** شاشة الترقيمة، وخيار «ابدأ ختمة جديدة».

### ادعم
انظر `content-guardrails.md` قسم الدعم. صفحة واحدة، بلا نوافذ منبثقة، وبلا تذكير بالدعم داخل القارئ أبداً.

## 3. نموذج البيانات

```ts
type Author = {
  id: string;
  displayName: string;          // كما وافق عليه الشيخ
  bio: string;                  // سطران
  consentRef: string;           // مرجع الإذن المكتوب
  consentDate: string;          // ISO
};

type QuranRef = { surah: number; fromAyah: number; toAyah: number };

type WirdItem =
  | { kind: "quran"; ref: QuranRef; repeat: number; audioId?: string }
  | { kind: "dhikr"; dhikrId: string; repeat: number; audioId?: string }  // نص الذكر وتخريجه في جدول مستقل
  | { kind: "note"; text: string };                                       // توجيه المعدّ، قصير

type Plan = {
  id: string;
  title: string;
  authorId: string;
  durationDays: 7 | 14 | 21 | 40;
  minutesPerDay: number;        // تقديري
  summary: string;
  days: { day: number; items: WirdItem[] }[];
  review: { shariaReviewer: string; safetyCheckedAt: string };
  version: number;
  publishedAt: string;
};

type Enrollment = {
  planId: string;
  planVersion: number;
  startedAt: string;
  completedDays: number[];      // لا يُخزَّن أي شيء عن الحالة
  reminder?: "after_fajr" | "after_maghrib" | "before_sleep";
};

type Khatma = {
  id: string;
  mode: "solo" | "group";
  title: string;
  intention?: string;           // اختياري، يُعرض لأعضاء الختمة فقط
  ownerId: string;
  members: { id: string; displayName: string }[];
  juz: { index: number; assigneeId?: string; doneAt?: string }[]; // 30 عنصراً
  targetDate?: string;
  completedAt?: string;
  inviteCode?: string;          // للجماعية
};
```

## 4. الإشعارات والتذكير

- تذكير واحد يومياً في الوقت الذي اختاره المستخدم، بنص هادئ: «وردك اليوم جاهز.»
- لا إشعار يذكر الأيام الفائتة، ولا إشعار بعد يومين من الصمت أكثر من مرة واحدة: «أكمل من حيث توقفت متى شئت.»
- في الختمة الجماعية: إشعار عند إتمام الختمة فقط، لا عند كل جزء.
- معاينة الإشعار لا تحتوي نيّة الختمة.

## 5. دون إنترنت والأداء

- النصوص كلها مضمّنة في التطبيق؛ الصوت يُحمّل مسبقاً للخطة النشطة.
- تطبيق ويب تقدّمي (PWA) خيار أول مناسب؛ حجم التحميل الأول أقل من 300KB دون الخطوط والصوت.
- الختمة الجماعية وحدها تحتاج اتصالاً، وتعمل بمزامنة متأخرة.

## 6. الخصوصية

- لا يُجمع أي بيان صحي أو وصف حالة. لا يوجد حقل لذلك أصلاً.
- الحساب اختياري (هاتف أو بريد) ولا يُطلب إلا للمزامنة أو الختمة الجماعية.
- النيّة في الختمة الجماعية مرئية لأعضائها فقط، ويمكن تركها فارغة.
- لا تحليلات إعلانية ولا مشاركة بيانات مع أي طرف.

## 7. المؤشرات والأحداث

| الحدث | يُستخدم لـ |
| --- | --- |
| `plan_started` (planId, duration) | أي المدد والمعدّين أكثر طلباً |
| `wird_completed` (planId, day) | الإكمال اليومي |
| `plan_completed` | معدل إتمام الخطة |
| `khatma_juz_done` (mode) | نشاط الختمة |
| `khatma_invite_accepted` | الانتشار عبر الختمة الجماعية |

مؤشرات البداية المقترحة: إكمال ورد اليوم الأول، العودة في اليوم السابع، نسبة إتمام الخطة، عدد المنضمين لكل ختمة جماعية. لا تُسجَّل أي أحداث تحتوي نصاً كتبه المستخدم.
