## 1. الفكرة والمبادئ

سند صفحة مخطوطة لا لوحة تحكم. ثلاثة مبادئ تحكم كل قرار:

- **الزخرفة وظيفة.** كل عنصر مزخرف يحمل معلومة: السبحة تعدّ الأيام، الوردة تعدّ الأجزاء، الجدول يقول «هذا هو الأهم الآن». إن لم يحمل العنصر معلومة فاحذفه.
- **ذهب قليل يعني ذهباً ثميناً.** الذهب يظهر حيث يوجد إنجاز أو رأس صفحة. لا يُستخدم للأزرار العادية ولا للنصوص الطويلة.
- **هدوء الليل.** أغلب الاستخدام في الصباح الباكر وقبل النوم. الوضع الليلي ليس نسخة معكوسة، بل ليل لازوردي له شخصيته.

## 2. الألوان

```css
:root {
  /* قرطاس النهار */
  --paper:        #ECEEF3;  /* ورق بارد مائل للزرقة، لا كريمي */
  --paper-2:      #E1E5EE;  /* سطح ثانٍ: الحاشية، الأسطر المظلّلة */
  --ink:          #1A1C2E;  /* حبر النص */
  --ink-soft:     #4A4F6A;  /* نص ثانوي */
  --lazward:      #23339A;  /* اللازورد: الإجراء الأساسي والروابط */
  --sarlawh-bg:   #1E2C86;  /* خلفية السرلوح */
  --gold:         #9E7420;  /* ذهب نصّي، يحقق التباين على القرطاس */
  --leaf:         #D9B45A;  /* ورق الذهب: الحبات والبتلات المكتملة */
  --zinjafr:      #A3392A;  /* الزنجفر: علامات الآيات والعدّاد فقط */
  --fayruz:       #2C7F7A;  /* الفيروز: حالة «تمّ» */
  --rule:         #C3C9DA;  /* خطوط التسطير */
}
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { /* انسخ قيم الليل أدناه */ }
}
:root[data-theme="dark"] {
  --paper:#0B1130; --paper-2:#121A42; --ink:#E7E3D4; --ink-soft:#A9AEC8;
  --lazward:#8C9BF0; --sarlawh-bg:#18225E; --gold:#E2BF63; --leaf:#E2BF63;
  --zinjafr:#E58A72; --fayruz:#62C1B8; --rule:#27316A;
}
```

قواعد الاستخدام:

| اللون | مسموح | ممنوع |
| --- | --- | --- |
| اللازورد | الزر الأساسي، الروابط، خلفية السرلوح | نص طويل |
| الذهب | الإنجاز، إطار الجدول، عنوان السرلوح | أزرار عادية، خلفيات واسعة |
| الزنجفر | علامة نهاية الآية، رقم العدّاد | أي شيء آخر؛ وليس لوناً للأخطاء |
| الفيروز | «تمّ»، الخطوة المكتملة | زخرفة |

الأخطاء تُكتب بالحبر مع أيقونة، لا بالأحمر، حتى لا تُخلط بالزنجفر المقدّس.

## 3. الخطوط والسلّم الطباعي

```html
<link href="https://fonts.googleapis.com/css2?family=Amiri+Quran&family=Reem+Kufi:wght@500;700&family=Readex+Pro:wght@300;400;600&display=swap" rel="stylesheet">
```

```css
--f-kufi:  "Reem Kufi", "Noto Kufi Arabic", sans-serif;      /* السرلوح والعناوين الكبيرة */
--f-quran: "Amiri Quran", "Amiri", "Noto Naskh Arabic", serif; /* القرآن فقط */
--f-ui:    "Readex Pro", "Noto Sans Arabic", system-ui, sans-serif; /* كل الواجهة */
```

| الدور | الخط | الحجم | الوزن | ارتفاع السطر |
| --- | --- | --- | --- | --- |
| عنوان السرلوح | Kufi | 1.75rem | 700 | 1.2 |
| عنوان قسم | Kufi | 1.25rem | 500 | 1.3 |
| نص القرآن | Quran | 1.6rem (قابل للتكبير حتى 2.4rem) | 400 | 2.3 |
| نص الواجهة | Readex | 1rem | 400 | 1.7 |
| حاشية/ملاحظة | Readex | 0.85rem | 300 | 1.6 |

قواعد: لا تستخدم Amiri Quran لغير القرآن. لا تكتب ذكراً أو حديثاً بخط القرآن؛ الأذكار بـ Readex بحجم أكبر قليلاً (1.15rem). طول السطر في القارئ لا يتجاوز 34em تقريباً.

## 4. التخطيط والشبكة

```
الجوال (الافتراضي)                     الشاشة العريضة ≥ 900px
┌──────────────────────┐              ┌───────────────┬────────────────────┐
│ ▓▓▓ السرلوح ▓▓▓  ☾ ⚠ │              │   الحاشية     │  ▓▓▓ السرلوح ▓▓▓   │
├──────────────────────┤              │  (ملاحظات،    │  المتن (30rem)     │
│  المتن               │  ┃حاشية      │   عدّادات)    │                    │
│  ╔══ الجدول ══╗      │  ┃رفيعة      │               │                    │
│  ║ ورد اليوم  ║      │  ┃           │               │                    │
│  ╚════════════╝      │              └───────────────┴────────────────────┘
├──────────────────────┤
│ اليوم الخطط الختمة ادعم │  ← شريط سفلي ثابت
└──────────────────────┘
```

- المتن على اليمين (بداية القراءة)، والحاشية على اليسار كما في المخطوط العربي.
- المحاذاة: النصوص تبدأ من اليمين. الوسط فقط لعنوان السرلوح، والوردة، والترقيمة.
- المسافات على سلّم 4px: 4، 8، 12، 16، 24، 32، 48.
- زوايا: 2px للجدول (حادة كالورق)، 999px للحبات فقط. لا زاوية 12px موحّدة.

## 5. المكوّنات التوقيعية

### السرلوح (رأس الشاشة)
شريط بلون `--sarlawh-bg` ارتفاعه 72–96px، داخله نقش نجمة ثمانية متكرر بالذهب بشفافية 0.35 عبر `<pattern>` في SVG، وفي الوسط خرطوشة (مستطيل بطرفين مقوّسين) تحمل اسم الشاشة بخط كوفي ولون `--leaf`. يُسطَّر أسفله بخطين: ذهب 1px ثم لازورد 1px بفاصل 2px.

نقش النجمة الثمانية (خلية 24×24):
```svg
<pattern id="girih" width="24" height="24" patternUnits="userSpaceOnUse">
  <path d="M12 2 L14.5 9.5 L22 12 L14.5 14.5 L12 22 L9.5 14.5 L2 12 L9.5 9.5 Z"
        fill="none" stroke="currentColor" stroke-width=".8"/>
</pattern>
```

### الجدول (الإطار المسطّر)
```css
.jadwal{
  border-radius:2px; padding:20px 18px;
  box-shadow: inset 0 0 0 1px var(--gold),
              inset 0 0 0 4px var(--paper),
              inset 0 0 0 5px var(--lazward);
}
```
لا يُستخدم إلا لعنصر واحد في الشاشة.

### السبحة (تقدّم الخطة)
حبات على منحنى متدلٍّ من اليمين إلى اليسار، مع «إمام» السبحة (شرّابة) في الطرف الأيسر.

- موضع الحبة i من n: `t = i/(n-1)`، `x = R - t*(R-L)`، `y = top + sag * sin(π t)`.
- نصف القطر: 10px إذا n ≤ 7، و7px إذا n ≤ 21، و5px إذا n = 40.
- حبة مكتملة: تعبئة `--leaf` وحدّ `--gold`. اليوم الحالي: تعبئة القرطاس وحلقة `--zinjafr` بسماكة 2px. القادم: تعبئة القرطاس وحدّ `--rule`.
- لكل حبة `aria-label` مثل «اليوم ٤: لم يكتمل».

### وردة الختمة
ثلاثون بتلة حول مركز (cx, cy). البتلة i (من 0):
```
step = 12°;  gap = 0.8°
a0 = -90° - i*step - gap;   a1 = -90° - (i+1)*step + gap;   am = (a0+a1)/2
P(r,a) = (cx + r·cos a, cy + r·sin a)
path = M P(r1,a0)  A r1 r1 0 0 0 P(r1,a1)  L P(r2,a1)  L P(r3,am)  L P(r2,a0)  Z
r1 = 0.44R,  r2 = 0.80R,  r3 = 0.91R
```
- الجزء الأول في الأعلى، والدوران عكس عقارب الساعة (اتجاه القراءة العربية).
- رقم الجزء بأرقام عربية عند نصف القطر (r1+r2)/2 بحجم صغير.
- في المركز نجمة ثمانية (16 رأساً بين نصفي قطر 0.36R و0.27R) يُكتب داخلها «١٢ / ٣٠».
- الحالات: مقروء لي → `--leaf`. غير مقروء → بلا تعبئة مع حدّ `--rule`. في الختمة الجماعية: جزء غيري المقروء → `--lazward` بشفافية 0.7، وغير المقروء → حدّ لازوردي متقطّع.
- كل بتلة زر: `role="button"`, `tabindex="0"`, وتستجيب لـ Enter والمسافة.

### الحاشية
عمود أو سطر بخلفية `--paper-2` ونص 0.85rem، يبدأ بعلامة صغيرة (نجمة ثمانية 10px). فيه: العدّاد، «متى تحتاج إلى طبيب؟»، ملاحظة المعدّ.

### الترقيمة (شاشة الإتمام)
نص في الوسط تتناقص أسطره كمثلث مقلوب، كما يختم النسّاخ مخطوطاتهم:
```
          تمّت الختمة بحمد الله
            في الرابع عشر من
              رمضان ١٤٤٨
               تقبّل الله
                  ❁
```
عرض الأسطر: 100%، 78%، 56%، 36%، ثم زهرة صغيرة. بخط Amiri (غير Quran) ولون الحبر، والزهرة بالذهب. بلا قصاصات احتفال ولا نجوم.

### العدّاد (في القارئ)
حلقة 48px بحدّ `--rule`، تمتلئ بالزنجفر مع كل نقرة (stroke-dashoffset)، وفي وسطها «٢ / ٣». عند الاكتمال تتحول إلى الفيروز وتُكتب «تمّ». النقر على العدّاد كله، لا على زر صغير.

## 6. المكوّنات العادية

- **الزر الأساسي:** خلفية `--lazward` ونص القرطاس، شكل خرطوشة: `clip-path: polygon(5% 0,95% 0,100% 50%,95% 100%,5% 100%,0 50%)`. ارتفاع 48px. عند التركيز: خلفية الحبر وإطار خارجي على عنصر غلاف.
- **الزر الثانوي:** نص لازوردي مع خط سفلي مزدوج رفيع، بلا خلفية.
- **قائمة الخطط:** أسطر مسطّرة (`border-bottom: 1px solid var(--rule)`)، لا بطاقات. كل سطر: العنوان بالكوفي الصغير، المدة، اسم المعدّ، وفي الحاشية عدد الأيام بحبات مصغّرة.
- **الشريط السفلي:** أربعة عناصر بأيقونات خطية بسيطة؛ العنصر النشط تحته نجمة ثمانية صغيرة بالذهب بدلاً من خط.
- **زر الطوارئ:** نص «طوارئ» في السرلوح بلون القرطاس على خلفية الزنجفر الداكن؛ هو الاستثناء الوحيد لاستخدام الزنجفر خارج القارئ، لأنه يجب أن يكون مرئياً دائماً.

## 7. الحركة

لحظة واحدة مدبّرة: عند «أتممت الورد» تتذهّب الحبة (انتقال تعبئة 600ms) مع وميض دائري خفيف يتوسع ويختفي (700ms). عند قراءة جزء تتذهّب البتلة بالطريقة نفسها. لا شيء آخر يتحرك تلقائياً.

```css
@media (prefers-reduced-motion: reduce){ *{animation:none!important; transition:none!important} }
```

## 8. الوصول والاتجاه والأرقام

- `<html lang="ar" dir="rtl">` دائماً. استخدم الخصائص المنطقية (`margin-inline-start`).
- الأرقام: `n.toLocaleString('ar-EG')`.
- التاريخ الهجري: `new Intl.DateTimeFormat('ar-SA-u-ca-islamic-umalqura',{day:'numeric',month:'long',year:'numeric'})` داخل try/catch.
- تكبير نص القرآن من الإعدادات حتى 150% دون كسر التخطيط.
- تباين النص العادي 4.5:1 على الأقل؛ الذهب النصّي `#9E7420` على القرطاس للعناوين الكبيرة فقط.
- `viewport-fit=cover` مع حشو `env(safe-area-inset-*)` للشريط السفلي والسرلوح.
